# Domain glossary / Glosario del dominio
Bilingual reference. Existing model and contract identifiers are retained; this glossary does not approve schema or route changes.
| Español | English / existing technical identifier |
|---|---|
| Promotor de marca | Brand Promoter / `Promoter` (role supported by `User`) |
| Tienda | Store / `Store` |
| Asignación a tienda | Store Assignment / `Assignment` |
| Mercadería | Merchandise |
| Recepción de mercadería | Goods Receipt / `Reception` |
| Detalle de recepción | Reception Item / `ReceptionItem` |
| Existencia operativa | Operational Stock |
| Inventario | Inventory |
| Ubicación física | Storage Location / `StorageLocation` |
| Movimiento de mercadería | Stock Movement / `StockMovement` |
| Cuota comercial | Sales Target |
| Avance comercial | Reported Sales Progress |
| Cumplimiento de meta | Target Achievement |
| Talla | Size |
| Variante de producto | Product Variant / `ProductVariant` |

`GoodsReceipt` is a possible future naming alternative, not an approved rename. Operational stock is not retailer-authoritative inventory; a receipt is not a sale; sales progress is reported, not POS-verified.
